# Hashpen — Support & Privacy Policy

**Hashpen** is a minimalist, distraction-free Markdown writing application for macOS.

## Support
If you have any questions, bug reports, feature requests, or need assistance with Hashpen:
- **Open an issue:** Use the [Issues](../../issues) tab at the top of this page.
- **Email:** info@spacecoding.it

---

## Privacy Policy
**Hashpen does not collect any personal data.**
- **Zero Data Collection:** Hashpen does not collect, store, share, or transmit any personal information, usage analytics, or telemetry.
- **100% Local Storage:** All documents, drafts, and preferences you create or edit with Hashpen stay locally on your Mac (or in the folders you explicitly choose to save them to).
- **No Third-Party Trackers:** The app contains no third-party SDKs, advertising, or external network requests.
